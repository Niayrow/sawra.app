Politique de confidentialité

Dernière mise à jour · 9 août 2026 · URL publique pour Google Play

Sawra est un lecteur de Coran (web, PWA et application Android). Cette page décrit les données traitées. Une version interactive est aussi disponible dans l’app (À propos → Confidentialité).

1. Sans compte (stockage local)

Favoris, thème du lecteur, volume, vitesse, téléchargements audio et reprise locale sont enregistrés sur l’appareil (localStorage / Cache Storage). Ces éléments ne sont pas envoyés à un serveur tant que vous n’êtes pas connecté.

2. Avec un compte GoMuslimLife

Si vous vous connectez, nous synchronisons favoris, reprise de lecture, préférences du lecteur et sélection de sourates. Pas de publicité, pas de revente d’historique d’écoute. L’authentification et le stockage cloud passent par Supabase. Vous pouvez vous déconnecter depuis l’onglet Compte.

3. Identifiants techniques

Sur mobile, un identifiant d’appareil local peut servir à la sync multi-appareils et aux sessions de lecture distante. Il n’est pas utilisé pour de la publicité ciblée.

4. Analytics

En production, des métriques anonymes de performance (Vercel Analytics / Speed Insights) peuvent être collectées pour améliorer la stabilité, sans publicité ciblée.

5. Audio tiers

Les récitations sont chargées depuis le catalogue public mp3quran.net. Sawra n’héberge pas les fichiers MP3.

6. Vos droits

Vous pouvez effacer les données locales (cache hors-ligne / données du site) et supprimer votre session cloud. Pour toute question : sofianeweb.fr · compte : GoMuslimLife.com.

7. Contact éditeur

Éditeur : Sofiane Web — sofianeweb.fr. Application : sawra.app · package Android : app.sawra.
